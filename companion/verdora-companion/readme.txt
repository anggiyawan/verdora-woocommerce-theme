Optional extras for the Verdora theme: WhatsApp chat buttons, basic SEO meta tags and a one-click demo product importer.

== Description ==

Verdora Companion adds features that belong in a plugin rather than in the Verdora theme:

* WhatsApp: a floating chat button, an "Ask via WhatsApp" button on product pages (the message includes the product name and link) and a "Chat Seller" shortcut in the Verdora home quick menu. Settings: Appearance > Customize > Verdora Settings > WhatsApp.
* SEO meta tags: a meta description and Open Graph tags for the home page, posts, pages, products and categories. Turned off automatically when Yoast SEO, Rank Math, AIOSEO, SEOPress or The SEO Framework is active.
* Demo content: Appearance > Verdora Demo Content imports 10 complete demo products with images (WooCommerce required). Everything it creates is marked, so "Delete Demo Content" removes only demo data.

The plugin works with any theme, but its Customizer sections and button styles are designed for Verdora.

Settings are stored as theme mods named `verdora_wa_*` and `verdora_seo_meta`, so values saved by earlier Verdora versions keep working.

= Privacy =

The plugin does not collect or send any data. WhatsApp links open wa.me only when a visitor clicks them.
