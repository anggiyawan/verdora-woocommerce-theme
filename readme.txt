A modern marketplace-style WooCommerce theme in emerald green, with a promo slider, quick menu and mobile app-style navigation.

== Description ==

Verdora brings the look and feel of large online marketplaces to your WooCommerce store, in a calm emerald green.

* Promo banner slider: a main text slide, your own uploaded banners (separate desktop and mobile images) and automatic "Sale" and "New Collection" slides built from your products. Autoplay pauses on hover and stops once a visitor takes control.
* Two side promo boxes, a colorful quick menu (Flash Sale, Discounts, Best Sellers, New Arrivals, Top Rated, All Products, My Orders) and category shortcuts with product photos or colored icons.
* Flash Sale row with a countdown, Featured Products and a Recommendations grid. Every home section can be shown, hidden and reordered.
* Shop page with a filter sidebar (categories, price range, on-sale products), product cards with sale badges, ratings and units sold.
* Single product page with a sticky gallery, units sold and custom info points. Works with both the classic and the block Cart and Checkout.
* Mobile first: app-style bottom navigation, off-canvas menu and a back to top button.
* Four menu locations, including dropdown submenus in the main navigation.
* 120+ Customizer options with live preview: colors (shades are calculated automatically), fonts, corner style, layout, banner, home sections, product cards and footer.
* Lightweight: no page builder, no jQuery dependency in the theme scripts, inline SVG icons and an option to use the device font so no web font is loaded.
* Accessible components: keyboard support for the slider, dropdowns and category picker, a skip link and ARIA attributes.
* Translation-ready, with an Indonesian translation included.

Verdora also works as a regular blog theme when WooCommerce is not active.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New.
2. Search for Verdora, then click Install and Activate.
3. Install and activate WooCommerce for the store features.
4. Go to Appearance > Verdora Settings to set up colors, the banner and the home page sections.

== Frequently Asked Questions ==

= Does Verdora require WooCommerce? =

No. Without WooCommerce, Verdora works as a blog theme. The store features (banner slider, quick menu, product sections, shop layout) appear once WooCommerce is active.

= How do I add dropdown menus? =

Go to Appearance > Menus, create a menu, assign it to the "Primary Navigation" location, and drag items slightly to the right below a parent item to make them sub items.

= How do I fill the store with sample products? =

WooCommerce ships with sample data. Go to Products > Import and choose the file wp-content/plugins/woocommerce/sample-data/sample_products.csv.

= Does the theme add SEO tags or chat buttons? =

No. Verdora only handles design and presentation, so it works with any SEO or chat plugin you prefer. The quick menu can be extended with the verdora_quick_links filter.

= Does the theme collect any data? =

No. Verdora does not collect or send any data. When a Google font is selected in the Customizer (the default is Plus Jakarta Sans), the font is loaded from Google Fonts, which receives the visitor's IP address. Choose "Device default font" under Appearance > Verdora Settings > General to load no web fonts at all.
